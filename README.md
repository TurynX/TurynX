## 🚀 Engenharia Aplicada & Destaques Técnicos
*Abaixo estão os principais conceitos de arquitetura consolidados no meu ecossistema de desenvolvimento, que você pode conferir direto nos meus repositórios:*

* **Arquitetura Limpa e Desacoplamento:** Implementação de APIs divididas por contextos isolados (como *Auth* e *Wallet*), garantindo que os Casos de Uso sejam independentes de frameworks e bancos de dados por meio de inversão de dependência.
* **Persistência de Dados e Migrations:** Modelagem de bancos relacionais utilizando Prisma ORM, gerenciando estados de tabelas complexas através de migrations bem estruturadas.
* **Conteinerização com Docker:** Criação de ambientes isolados e reprodutíveis utilizando Docker e Docker Compose para orquestração de bancos de dados locais.
* **Aplicações em Tempo Real e Segurança:** Desenvolvimento de comunicação bidirecional com WebSockets e proteção de rotas através de Guards customizados para validação de tokens JWT.
